Paper Leak Incidents Analysis — India (2004–2026)

Data Quality Tracing & Power BI Analysis

1. The Problem

Exam paper leaks in India have become a significant national issue, affecting millions of students and undermining the integrity of educational institutions. However, data regarding these incidents is often scattered across news reports, government press releases, and regional databases. The goal of this project was to trace, validate, and centralize this data to identify trends and geographical hotspots over a 22-year period.

2. The Solution

I built a centralized Power BI dashboard that visualizes reported paper leak incidents across various Indian states. Because much of the source data was unstructured, I utilized Python for initial data validation, cleaning, and text extraction before loading it into Power BI for modeling and visualization.

Project Scope: Analyzed 110+ reported incidents across 25 Indian states, spanning from 2004 to 2026.

3. Methodology & Tech Stack

  • Data Extraction: Gathered incident reports from public news databases and official government releases.
  • Data Validation: Used Python (Pandas) to clean duplicates, standardize state names, and handle missing dates/values.
  • Visualization: Created a star-schema model in Power BI to build interactive dashboards for year-wise trends and state distribution.

4. Key Insights & Results

The analysis revealed that while incidents have occurred across the country, there are distinct regional clusters where paper leaks are more frequent. The dashboard allows users to filter by year and state to understand the severity of the issue.

5. Business Value

This project demonstrates the ability to take unstructured, messy public data, validate it, and build a clean, professional data model. It provides stakeholders with a historical view of a critical national issue, aiding in the development of preventative policies.
